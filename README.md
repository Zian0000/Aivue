# AI Usage Menu Bar

這是一個 macOS 狀態列工具，用來顯示 Codex（ChatGPT 方案）與 Claude 的區段用量、總用量及重置時間。

## 專案狀態

- 第一階段：資料取得技術驗證 — 95%（核心驗收完成）
- 第二階段：單平台 Menu Bar 骨架 — 95%
- 第三階段：雙平台整合 — 95%
- 第四階段：產品化與測試 — 主要功能、App 圖示及 Sparkle 更新架構已實作；正式簽署、公證與發布驗收待完成
